## Overview

A cybersecurity project focused on identifying and investigating suspicious PowerShell execution activities that may indicate malicious behavior or potential attacks against Windows systems.

## Objectives

- Understand how PowerShell can be abused by attackers.
- Identify suspicious PowerShell execution patterns.
- Analyze Windows event logs related to PowerShell activity.
- Detect potentially malicious commands and scripts.
- Investigate suspicious execution activities.

## Technologies

- PowerShell
- Windows
- Windows Event Logs
- SIEM
