## Overview

A cybersecurity lab focused on detecting and investigating attacks against a Windows Active Directory environment using Splunk and Windows event logs.

## Objectives

- Understand common attacks targeting Active Directory environments.
- Collect and analyze Windows security events.
- Develop detection queries using Splunk SPL.
- Investigate suspicious activities and identify potential threats.

## Technologies

- Splunk
- Windows Server
- Windows 10
- Active Directory
- Sysmon
