## Overview

An Incident Response Management System built in PostgreSQL for recording and analyzing cybersecurity incidents, investigations, evidence, affected assets, and response actions.

## What I Built

- A relational schema with users, playbooks, assets, incidents, investigations, evidence, response actions, and junction tables linking users and assets to incidents.
- Sample records to demonstrate incident severity, status, assignments, evidence collection, and response workflows.
- Analysis queries covering incident counts by severity and status, playbook usage, affected assets, evidence, investigations, response actions, and user assignments.

## Tools and Techniques

- PostgreSQL — relational database design and SQL queries
- pgAdmin — database exploration and query execution
- SQL joins, aggregations, and filtering for incident analysis
