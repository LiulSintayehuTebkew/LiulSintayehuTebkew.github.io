## Overview

An end-to-end analytics and machine learning project investigating e-commerce returns across 34,500 orders, 7 product categories, and 5 regions. The goal was to identify return patterns, quantify financial losses, and score the risk of future returns.

## What I Did

- Cleaned and prepared the data, then used SQL for business analysis.
- Explored return drivers with statistical analysis and feature engineering.
- Built and evaluated return-risk models with scikit-learn and XGBoost.
- Created a four-section Power BI dashboard: Executive Overview, Return Analysis, Financial Impact, and Risk Scoring.

## Key Findings

- Fashion and Electronics had the highest return rates.
- "Not as described" was the leading cause of financial losses.
- Product and fulfilment issues accounted for more than 98% of return-related losses.
- Returned orders had significantly higher average values.
- Profit margin, shipping cost, and price were the strongest return predictors; delivery speed had limited impact.

## Tools and Techniques

- Python — Pandas and NumPy for cleaning and analysis
- SQL — PostgreSQL business queries
- scikit-learn and XGBoost — return risk prediction
- Power BI — interactive dashboards
