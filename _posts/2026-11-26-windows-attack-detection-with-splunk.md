## Overview

A hands-on cybersecurity lab demonstrating how Windows attacks can be detected and investigated using Splunk, Sysmon, and Atomic Red Team.

## Objectives

- Generate simulated attack activity in a Windows environment.
- Collect endpoint telemetry using Sysmon.
- Forward Windows event logs to Splunk.
- Develop detection queries using SPL.
- Investigate suspicious activities through security events.

## Technologies

- Splunk
- Windows 10
- Sysmon
- Atomic Red Team
- Kali Linux
